## Resumen: Diseño por familia de pantalla

| Grupo | Resolución | Forma | Táctil | Tech | Dispositivos | Caso de uso |
|---|---|---|---|---|---|---|
| **Pequeña MIP** | 240×240 | round | No | MIP | fr745, fr945, fenix7s | Corredores con presupuesto, resistencia + batería |
| **Media MIP** | 260×260 | round | No/Sí | MIP | fr255, fr955, fenix7 | Corredores premium (batería larga, datos continuos) |
| **Grande MIP** | 280×280 | round | Sí | MIP | fenix7x, fenix8solar, enduro3 | Multideporte (running+gym+ergo), duración extrema |

| **AMOLED grande** | 416×416 | round | Sí | AMOLED | fr265, fenix8, epix2, instinct3amoled | Multideporte premium (UI completo) |
| **AMOLED gigante** | 454×454 | round | Sí | AMOLED | fr965, fr970, fenix847mm, venu3 | Ultra-premium, pantalla máxima |
| **Rectangular** | 448×486 | rectangle | Sí | AMOLED | venux1 | Uso extendido de pantalla (tablets) |

### Conclusiones para desarrollo:

1. **Pantallas táctiles (AMOLED + algunos Fenix MIP)**: Permiten UI interactiva completa. Ideal para menús complejos, control de sesión en vivo.

2. **Pantallas no-táctiles (MIP antiguos, Instinct Solar pequeño)**: Limitadas a 5 botones físicos. Requieren navegación estricta (UP/DOWN/ENTER/MENU/ESC).

3. **Rango de memoria**:
   - Mínimo: **131 KB** (instinct3solar → debe ser UI mínima)
   - Típico: **768 KB** (AMOLED, MIP modernos)
   - Máximo: **1.3 MB** (fr745/fr945 antiguos)

4. **API mínima recomendada**: **5.2.0** cubre el 90% de dispositivos. **6.0.2** da acceso a sensores mejorados.

5. **Para HYROX hybrid específicamente**: El flujo debe soportar:
   - Running (GPS) → todos tienen GPS multibanda
   - Ergómetro (sin GPS, pero Accel) → todos tienen acelerómetro
   - Estaciones de fuerza (RIR/RPE tácticos) → entrada manual (buttons + touch en AMOLED)
   - Barometer para altitud en box → todos menos fr745/fr945
