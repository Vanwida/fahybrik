01 · Qué toca ahora

No se lanza ningún agente hasta que elijas hilo.

Construir sin hilo es exactamente el gasto que quieres cortar: Grok y Claude releen media app y rehacen algo ya firmado.

Default mientras no eliges: tú miras las 6 pantallas de Carrera en /es/design. Eso no gasta tokens de agente. Si firmas, el primer átomo es NavigationStack + hub + historial. Si la rama PM5 es el hilo, dímelo y aparco Carrera.

02 · Reglas de gasto (esto es el producto)

1 átomo / sesión

Un objetivo, un done, un worker. «Sigue con la app» está prohibido. Si el corte no cabe en 8 turns de Grok, está mal cortado.

Quién paga

Hermes (yo): 1–3 líneas. Grok Build: default. Claude Code Max: solo UI/UX gorda. Cero API de Anthropic. Cero Cursor en paralelo.

No se pega el repo

El worker recibe la entrada de DECISIONS de ESA pieza + la spec + 4 pistas. Nunca FOCUS entero, nunca DECISIONS entero.

Espera = no construir

Si falta tu visto bueno o un ZIP, la fila se queda en naranja. Inventar para no parar es tirar dinero.

El patrón caro que ya no se repite

Sesión larga + varios dominios + FOCUS de 4.000 líneas en el contexto + reabrir una decisión firmada (CTA de tests en Carrera, sexta pestaña, ATR). El brief lleva el NO HACER arriba. Si una sesión falla, la lección se escribe en la fila. No se relanza el mismo prompt.

04 · El brief — tú no lo escribes

Plantilla fija. Corta a propósito. El gasto se va en contexto inútil, no en el modelo.

Objetivo: (una frase)
Criterios de done: 3–6 observables
Contexto: 4–8 líneas. Por qué existe.
Ley ya firmada (NO reabrir): citas de DECISIONS / mapa de ESA pieza
Pistas (hipótesis): archivos. Si el código dice otra cosa, manda el código.
Fuera de alcance: lista
Tope: grok -p --max-turns 8 --always-approve
         o claude -p --max-turns 8 (solo UI)
Verificar: comandos concretos
Al terminar: actualizar docs/tablero.html + FOCUS corto.
No git add -A. No stash. No hinchar FOCUS.

06 · Dónde puede fallar

  • Tú abres otra sesión de Claude/Grok a la vez que yo. Eso duplica el gasto y pisa el tablero. Si trabajas fuera, dímelo.
  • FOCUS vuelve a crecer. Cualquier agente que añada una sección «Ahora» de más de 12 líneas está rompiendo el contrato. El brief lo dice.
  • Dos hilos en esta rama. PM5 y Carrera no se mueven en el mismo checkout.
  • Brief cerrado de más. Las rutas de archivo son hipótesis. El código manda.
Este fichero se actualiza en el mismo commit que el trabajo. Si el chat dice una cosa y el tablero otra, manda el tablero.
