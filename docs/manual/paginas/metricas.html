Métricas del funnel

Lo usa Pablo Interno / negocio

El embudo de un vistazo: visitas → onboarding → cita → llamada → alta, con dónde se cae la gente entre etapas y la tendencia por semana o por mes. Sirve para ver qué parte del ingreso conviene arreglar primero.

Mockup · datos de ejemplo

Cómo lo usa el coach

  1. Entra en la sección Métricas.
  2. Elige el rango: 7 días, 30 días o todo.
  3. Lee el funnel con las tasas de conversión y las caídas entre etapas, la conversión por objetivo, el resultado de las llamadas y el precio medio.
  4. Usa las caídas para decidir qué mejorar: la web, el onboarding o las ofertas.

Qué ve el atleta

Nada. Es una vista interna de negocio — el atleta no ve estas métricas.

Reglas del sistema

  • Todo está derivado de datos reales — nada inventado.
  • Las visitas se cuentan cookieless y sin PII: un hash con salt que cambia cada día, nunca la IP; y solo desde que se instrumentó la medición (antes no hay histórico).
  • Una cohorte reciente aún está madurando: un lead de ayer no ha tenido tiempo de convertir, así que el último tramo del funnel se llena con los días.
